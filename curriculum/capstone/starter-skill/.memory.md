## What This File Is

This is the `.memory.md` for your new mental model. It accumulates lessons,
failure modes, and observations so that any future agent — or student — who uses
this skill doesn't have to re-derive what you already figured out.

The MUSE paper calls this "skill-level memory." Every time the skill is used and
something surprising happens, a note goes here. Over time, this file is more
valuable than the model itself — it's the hard-won experience.
